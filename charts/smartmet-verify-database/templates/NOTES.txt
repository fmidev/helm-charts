PASSWORDS
---------
{{ len $generated }} role password(s) are managed by this release. Read them with:
{{ range $role := $generated }}
  kubectl -n {{ $.Release.Namespace }} get secret {{ include "smartmet-verify-database.roleSecretName" (list $ $role) }} \
    -o jsonpath='{.data.password}' | base64 -d; echo   # {{ $role.name }}
{{- end }}

Record them in your secret manager now. `helm uninstall` deletes both these
Secrets and (via CNPG) the database volumes.

NOTE: password reuse across upgrades relies on Helm's `lookup`, which does not
work under `helm template`, client-side `--dry-run`, or Argo CD. Preview an
upgrade with `--dry-run=server`. For GitOps, set auth.generatePasswords=false
and supply roles[].existingSecret instead.
{{- end }}

Verify each supplied Secret carries a `username` key matching its role exactly,
or CNPG will refuse to reconcile that role:

  kubectl -n {{ $.Release.Namespace }} get secret {{ $role.existingSecret }} \
    -o jsonpath='{.data.username}' | base64 -d; echo   # must be: {{ $role.name }}
{{- end }}
{{- end }}
